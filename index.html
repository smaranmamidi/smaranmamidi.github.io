About

I’m an SDE intern at Karix Mobile Pvt Ltd and a final-year Integrated M.Tech student in Software Engineering at VIT Vellore. My strongest ground is full-stack and backend engineering: real-time systems with Socket.IO, services in Node.js and FastAPI, and data layers in PostgreSQL, MySQL and Redis.

I pair that with machine learning and performance work. I’ve moved a K-Means image segmentation from 117 seconds on CPU to 1.3 seconds on a GPU with CUDA, built an NLP moderation pipeline for live chat, and shipped a medical-imaging system across desktop, mobile and cloud. I like practical applications where measured results matter.
